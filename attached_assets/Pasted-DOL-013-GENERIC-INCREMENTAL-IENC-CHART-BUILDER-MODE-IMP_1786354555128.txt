==================================================
GOAL
==================================================

Generalize the existing validated two-cell IENC pipeline into a generic,
incremental, per-cell Dolphin Chart Builder.

The intended future user workflow is:

1. Put official .000 IENC files into:
   data/nautical/chart-source/

2. Run one builder command.

3. The pipeline:
   - discovers cells automatically
   - calculates SHA-256
   - extracts official metadata
   - verifies cell identity
   - processes new/changed cells
   - skips unchanged validated cells
   - validates each cell
   - generates per-cell outputs
   - generates catalog.json
   - publishes only after the complete intended build passes

DOL-013 itself must test ONLY the two existing pilot cells.

==================================================
1. SOURCE DISCOVERY
==================================================

Do NOT require a manually maintained checksum row for every normal chart update.

Discover:

data/nautical/chart-source/*.000

For every discovered source:

- calculate SHA-256
- extract official dataset metadata
- derive/verify sourceCellId from authoritative metadata where available
- preserve:
  - filename
  - SHA-256
  - cellId
  - edition
  - issueDate
  - updateApplicationDate
  - producer

Never fabricate cell identity or missing metadata.

If filename-derived identity and official dataset metadata conflict:
FAIL that cell.

A generated build/source registry is allowed, but it must be generated by
the pipeline rather than manually authored for every chart.

==================================================
2. RAW SOURCE SAFETY
==================================================

Raw .000 files are immutable.

Never edit, normalize, rename destructively, or overwrite the raw source.

Preserve source SHA-256 in provenance and cell manifest.

==================================================
3. GENERIC PIPELINE
==================================================

Remove the hardcoded two-cell assumptions identified in the completed audit.

Refactor only what is necessary in:

    soundings.geojson
    cell-manifest.json

==================================================
4. UNIVERSAL VALIDATION
==================================================

Separate validation into:

A. universal safety invariants
B. pilot regression fixtures

Universal invariants must apply to every future cell.

Preserve at minimum:

- valid GeoJSON
- expected geometry types
- no empty geometries
- no NaN/Infinity coordinates
- sourceCellId present
- source SHA-256 present
- provenance present
- pipelineFeatureId present
- identifier integrity
- no duplicate forbidden IDs
- datum metadata present where applicable
- banned inferred NAP fields absent
- official source identity preserved

SOUNDG SAFETY CONTRACT:

raw Z > 0
= charted depth below chart datum
= relation "below"

raw Z < 0
= drying height above chart datum
= relation "above"

raw Z = 0
= relation "at"

Original signed Z must remain unchanged.

NEVER use abs() during normalization.

Datum truth remains:

SDAT 42:
"Approximate LAT"
VERIFIED_FROM_OFFICIAL_DOCUMENTATION

VDAT 24:
"Local Datum"

Local Datum = NAP:
UNVERIFIED

Do not infer NAP.

==================================================
6. INCREMENTAL BUILD
==================================================

Use SHA-256 as the change identity.

If:

current source SHA-256
==
previous PASS cell-manifest source SHA-256

AND required validated output files exist,

then mark cell:

UNCHANGED

and skip expensive GDAL extraction/normalization where safe.

If:

- source is new
- SHA changed
- previous validation != PASS
- required output is missing

then process again.

Do not use timestamps as the truth source.

==================================================
7. FAILURE POLICY
==================================================

A failed intended cell must NEVER be silently omitted while the build is
reported as successful.

Example:

84 cells discovered
83 PASS
1 FAIL

Overall result:
FAIL

The previous published validated dataset may remain intact.

Do not promote a new complete catalog/dataset until all intended discovered
cells have passed.

Report failed cellId and reason clearly.
