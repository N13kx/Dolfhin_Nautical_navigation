IMPORTANT:
- Work only on feature/v0.2.1-nautical-data.
- Do not merge to main.
- Do not integrate chart data into the Dolphin UI yet.

- Do not start routing.

- 1R76W8LI.000
- 1R76W8RI.000

Treat them as read-only source samples.

PHASE 3 — FILE FORENSICS
==================================================

For both cells, collect:

- exact filename
- byte size
- SHA-256 checksum

- DSPM presence
- standard edition metadata where formally decoded
- warnings/errors

PHASE 4 — FORMAL DATASET METADATA EXTRACTION
==================================================

Using an actual S-57-capable reader where available, extract and compare:

- dataset name
- edition number

- update application date
- standard edition
- product specification
- producer agency

- horizontal datum
- vertical datum
- sounding datum
- coordinate multiplier
- sounding multiplier

For every field report:

- decoded field name
- raw value
- interpreted value
- confidence
- absent/unknown state

Example record IDs

- classes in both cells
